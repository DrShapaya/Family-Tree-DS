# История изменений

## 2.5.1

- Ускорены перенос карточек, ввод текста и сохранение больших деревьев.
- Фото и вложения вынесены из JSON в отдельное локальное хранилище.
- Добавлен переносимый `.ftree` со всем деревом, фотографиями и документами.
- Добавлены PDF, тайловый PNG и обычный PNG с пятью уровнями качества.
- Максимальное разрешение обычного PNG увеличено до 64 мегапикселей.
- Улучшены Undo/Redo, фоновое сохранение, импорт и защита от нехватки памяти.
- Исправлено мерцание фотографий в карточках.
- Добавлен локальный диагностический журнал без персонального содержимого.

Подробное пользовательское описание выпуска публикуется вместе с GitHub
