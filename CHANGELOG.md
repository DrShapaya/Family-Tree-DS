# История изменений

## 2.6.0

- При восстановлении сначала открывается само дерево, а фото и вложения
  продолжают загружаться в фоне, не блокируя работу с приложением.
- Глава дерева может оставить отдельному участнику только просмотр или снова
  разрешить правки; право применяется на GitHub и в интерфейсе участника.
- Приглашение теперь содержит обычную кликабельную HTTPS-ссылку, а ключ
  передаётся как форматированный моноширинный блок с текстовым запасным
  вариантом для приложений, которые не поддерживают оформление.
- Добавлен скрытый раздел онлайн-деревьев по пяти нажатиям на номер версии.
- После переустановки или смены телефона приложение находит доступные текущему
  GitHub-аккаунту деревья и позволяет загрузить выбранное вместе с медиа.
- Поиск существующего дерева запускается после входа и остаётся отдельным
  действием в меню, если пользователь отложил восстановление.
- Нажатие на ключ приглашения сразу копирует его.
- Полностью обновлены интерфейс секретного меню, окна входа, подключения,
  участников и подтверждений: единый стиль, понятные статусы и крупные действия.
- Синхронизация ускорена условными запросами, кэшем списка медиа и загрузкой
  вложений только при реальном изменении дерева.
- Оборванная отправка или загрузка медиа автоматически повторяется; оставшийся
  на GitHub неполный файл удаляется перед безопасной повторной отправкой.
- В карточке ошибки появилась кнопка немедленного повтора синхронизации, а
  статусы показывают номер файла и попытки восстановления.
- Канал приглашений теперь создаётся последним и удаляется, если настройка
  нового дерева не завершилась.
- Локальные правки записываются в журнал до отправки, а служебные файлы —
  атомарно: перезапуск или сбой сети больше не должен терять изменения.
- Привязка дерева проверяет постоянный GitHub ID аккаунта, а ответы на
  приглашения принимаются только от владельца канала.
- Закрыты гонки между выходом, повторным входом и уже запущенной
  синхронизацией; отменённый OAuth больше не может восстановить старую сессию.
- Реализован вход в GitHub через Device Flow без Client Secret в APK.
- В официальную сборку добавлен публичный OAuth Client ID AndroidFT, поэтому
  вход работает без ручной настройки Gradle.
- Исправлено зависание повторного входа после закрытия окна кода или временного
  сетевого сбоя; добавлены отмена, повторные подключения и понятные статусы
  ожидания подтверждения GitHub.
- Исправлено восстановление OAuth после возврата из браузера: GitHub-запросы
  используют текущую Android-сеть и пережидают временный сбой DNS.
- Основной вход заменён на однокнопочный браузерный OAuth с автоматическим
  возвратом в AndroidFT, PKCE и проверкой `state`; код оставлен как резерв.
- GitHub-токен сохраняется в Android Keystore и используется между запусками,
  пока пользователь сам не выйдет или не отзовёт доступ.
- Любой пользователь может создать собственный приватный репозиторий дерева.
- Добавлены зашифрованные ключи приглашений без отдельного сервера.
- Приглашения GitHub подтверждаются приложением автоматически.
- Глава может просматривать и отключать участников, а также менять ключ.
- Добавлена независимая синхронизация участников и трёхстороннее слияние
  параллельных изменений.
- Добавлена полная потоковая синхронизация фото, документов, аудио и видео
  через приватные GitHub Release Assets без прежнего ограничения 8 МБ.
- Фоновое получение изменений больше не сбрасывает масштаб и положение дерева;
  автоматическое вписывание остаётся только при первом запуске и по кнопке.
- Поддерживаются текущие лимиты приложения: фото до 30 МБ, вложения до 100 МБ
  и видео до 500 МБ; старый формат медиа остаётся совместимым.
- OAuth-токен и секрет приглашения защищены Android Keystore.

## 2.5.1

- Ускорены перенос карточек, ввод текста и сохранение больших деревьев.
- Фото и вложения вынесены из JSON в отдельное локальное хранилище.
- Добавлен переносимый `.ftree` со всем деревом, фотографиями и документами.
- Добавлены PDF, тайловый PNG и обычный PNG с пятью уровнями качества.
- Максимальное разрешение обычного PNG увеличено до 64 мегапикселей.
- Улучшены Undo/Redo, фоновое сохранение, импорт и защита от нехватки памяти.
- Исправлено мерцание фотографий в карточках.
- Добавлен локальный диагностический журнал без персонального содержимого.

Подробное пользовательское описание выпуска публикуется вместе с GitHub
Release.
