🌿 Family Tree DS 2.8.0 — большое обновление

🎨 Новая Мастерская

• Добавлена большая коллекция оформлений дерева.
• Появились дымные, стеклянные, огненные и растительные карточки.
• Можно отдельно выбирать оформление карточек, краёв, полотна, связей, экспорта и виджетов.
• За просмотр короткой рекламы начисляются жетоны, которые можно тратить на новые оформления.

🖼 Обновлённый экспорт

• Добавлен полноценный предпросмотр PNG с масштабированием и перемещением.
• Область изображения теперь можно свободно выбирать до самых краёв дерева.
• Настраиваются качество, размер текста, фон, рамка, сетка, линии поколений, вид карточек и количество деталей.
• Большое изображение можно автоматически разделить на несколько частей.
• Экспорт PDF стал понятнее: дерево можно разместить на одной странице или подготовить для печати по листам.
• В разделе файлов появились быстрые действия для отправки дерева и сохранения PNG.

✨ Улучшения приложения

• Фильтры списка людей заранее показывают количество найденных записей.
• Полностью переведены на английский Мастерская, список обновлений и оставшиеся элементы интерфейса.
• Стало аккуратнее окно «О нас», раздел обновлений, навигация и боковые кнопки.
• Исправлено отображение переключателей при изменении масштаба интерфейса.
• Улучшена производительность сложных визуальных эффектов и больших деревьев.
• Исправлены небольшие ошибки и недочёты интерфейса.
