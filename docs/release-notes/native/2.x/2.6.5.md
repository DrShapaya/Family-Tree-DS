# Family Tree DS 2.6.5

Объединённое обновление после версии 2.6.0.

## Русский

- Добавлен английский интерфейс с автоматическим определением языка и ручным выбором в параметрах.
- Обновлены тёмная тема, окно языка, панели инструментов и управление выделением.
- Карточки стали крупнее и информативнее; улучшены компактный режим, фотографии, даты и места.
- Добавлены оценка здоровья дерева, индикаторы качества карточек и быстрый переход к исправлению данных.
- Улучшены меню карточки, добавление нескольких родственников, семейные связи и цвета по фамилии.
- Фото сохраняются напрямую в галерею, а отправляемая биография содержит фото и заполненные сведения.
- Исправлены лассо, групповое удаление, границы и изменение размера рабочей области.
- Полностью переработано умное упорядочивание: семейные ветви размещаются устойчивее, а после добавления родственника перестраивается только затронутая часть дерева.
- Файлы `.ftree` открываются из Telegram, проводника и других приложений в отдельном окне AndroidFT.
- Перед заменой текущего дерева другим файлом показывается предупреждение с возможностью отмены.

## English

- Added an English interface with automatic language detection and manual selection in Settings.
- Updated the dark theme, language dialog, tool panels, and selection controls.
- Cards are larger and more informative; compact mode, photos, dates, and places were improved.
- Added a tree health score, card quality indicators, and quick navigation to data fixes.
- Improved the card menu, multi-relative creation, family links, and surname-based colors.
- Photos can be saved directly to the gallery, while shared biographies include a photo and completed details.
- Fixed lasso selection, multi-card deletion, workspace boundaries, and workspace resizing.
- Smart layout was completely reworked: family branches are placed more consistently, and adding a relative rearranges only the affected part of the tree.
- `.ftree` files now open from Telegram, file managers, and other apps in a separate AndroidFT task.
- A confirmation is shown before another file replaces the current tree.
