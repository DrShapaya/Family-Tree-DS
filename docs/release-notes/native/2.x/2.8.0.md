# Family Tree DS 2.8.0

Большое обновление по сравнению с версией 2.7.4.

## Мастерская и оформления

- В меню «Ещё» появилась Мастерская с жетонами, бонусами и большой коллекцией оформлений дерева.
- Добавлены дымные, стеклянные, огненные и растительные карточки, новые полотна, стили связей, рамки экспорта и рамки виджетов.
- Оформление карточек, краёв и других элементов можно выбирать независимо.
- За просмотр короткой рекламы начисляются жетоны для открытия новых оформлений.
- Улучшены огненные эффекты, бумажное полотно и производительность больших деревьев с растительным оформлением.

## Экспорт

- В разделе «Файлы и экспорт» появились быстрые действия для отправки дерева и сохранения PNG.
- Экспорт PNG получил чёткий предпросмотр с масштабированием, перемещением и свободным выбором области.
- Для изображения можно настроить качество, размер текста, фон, рамку, сетку, линии поколений, вид карточек и количество деталей.
- Большие изображения можно автоматически разделять на несколько частей.
- Экспорт PDF стал понятнее: дерево можно разместить на одной странице или подготовить для печати по листам.

## Удобство и исправления

- Фильтры списка людей заранее показывают количество найденных записей и позволяют быстро отключать выбранные условия.
- Дополнен английский перевод Мастерской, списка обновлений и оставшихся элементов интерфейса.
- Улучшены окно «О нас», компактный раздел обновлений, навигация и боковые кнопки.
- Исправлено отображение переключателей при изменении масштаба интерфейса.
- Исправлены затемнение меню «Ещё», положение оценки дерева и другие небольшие ошибки интерфейса.
