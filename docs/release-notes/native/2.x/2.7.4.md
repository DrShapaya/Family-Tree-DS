# Family Tree DS 2.7.4

Небольшое обновление совместимости интерфейса и обучения.

## Русский

- Версия больше не занимает место в шапке дерева; онлайн-дерево открывается красивой отдельной кнопкой из меню «Ещё» без скрытых жестов.
- Нижнее меню автоматически учитывает системную панель навигации и больше не перекрывается тремя системными кнопками или жестовой полосой.
- Предложение пройти обучение показывается только один раз и автоматически отключается для уже заполненного дерева.
- Обучение полностью переработано в безопасный интерактивный обзор: открытый раздел остаётся на экране до нажатия «Далее», а пользовательское дерево не изменяется.
- В разделе «Люди» появился умный поиск обычным языком: без фото, без даты рождения, живые/умершие, годы и диапазоны лет, ближайшие дни рождения, предки, потомки и родственники человека.
- Приложение показывает, как поняло запрос, а также хранит недавние запросы и сохранённые подборки.
- В альбоме «Все аватары» появился поиск по имени, году и месту.
- «Быстрый старт» теперь позволяет создать до трёх поколений, добавив родителей отца и матери.
- В меню «Дерево» появилось упорядочивание только выделенных карточек, активной ветки или потомков выбранного человека.
- Авторасстановка получила локальное обучение весов: после ручной коррекции приложение постепенно подстраивает решатель под стиль пользователя.
- Добавлен временный режим ИИ-логов для тестирования авторасстановки; журнал можно скопировать без ФИО, фото и заметок.
- В меню «Ещё» выровнены внутренние и внешние отступы.

## English

- The version no longer takes up space in the tree header; Online Tree now has a prominent button in More and no longer relies on a hidden gesture.
- The bottom menu now respects the system navigation area and is no longer covered by the three-button navigation bar or gesture handle.
- The training offer is shown only once and is automatically disabled when the user already has a populated tree.
- Training has been rebuilt as a safe interactive tour: an opened section remains visible until Next is tapped, with precise button highlights and no changes to the user's tree.
- The People section now has natural-language smart search for missing photos, missing birth dates, living/deceased filters, years and year ranges, upcoming birthdays, ancestors, descendants, and a person's relatives.
- The app shows how it understood the query and keeps recent queries plus saved search collections.
- The All Avatars album now has search by name, year, and place.
- Quick Start can now create up to three generations by adding parents for the entered father and mother.
- The Tree menu can now arrange only selected cards, the active branch, or the selected person's descendants.
- Auto-arrange now has local weight learning: after manual corrections, the solver gradually adapts to the user's layout style.
- A temporary AI layout log mode was added for testing; logs can be copied without names, photos, or notes.
- Spacing around and inside the More menu is now consistent.
