# Топ донатеров и сбор на сервер

Единый источник данных — `app/src/main/assets/supporters.json` в официальном
репозитории `DrShapaya/Family-Tree-DS`. Приложение читает этот файл по HTTPS
из GitHub при открытии экрана «О нас», поэтому после публикации изменения
видны всем пользователям без выпуска новой версии APK. При отсутствии сети
используется встроенная копия из APK.

Менять файл могут только владельцы и участники с правом записи в официальном
репозитории. Токены GitHub в приложение не вшиваются: обычные пользователи
имеют только публичный доступ на чтение.

Пример записи:

```json
{
  "version": 2,
  "displayLimit": 5,
  "fundraiser": {
    "title": "Сбор на сервер",
    "description": "Помогите Family Tree DS работать быстрее и надёжнее для всех.",
    "goal": 30000,
    "raised": 12500,
    "currency": "RUB"
  },
  "supporters": [
    {
      "name": "Имя или ник",
      "amount": 5000,
      "currency": "RUB",
      "color": "#8B7CFF",
      "showHeart": true,
      "order": 0
    }
  ]
}
```

В топ попадают только записи с положительной суммой. Если указан `order`,
приложение сохраняет порядок из админ-панели; иначе записи сортируются по сумме.
Количество видимых мест задаётся через `displayLimit`. Цвет должен быть записан
в формате `#RRGGBB`, а `showHeart: true` показывает сердечко рядом с ником.
Полоса сбора автоматически учитывает сумму всех донатов в валюте сбора. Поле
`fundraiser.raised` можно использовать для дополнительной ручной суммы —
приложение выбирает большее из ручного значения и суммы записей донатеров.
