# Импорт GEDCOM и экспорт для просмотра

Основание: обсуждение в теме «Offtop | Офтоп» группы https://t.me/ChatFamilyTree, прочитанное 6 октября 2026 года. Основная программа пользователя — «Древо Жизни»; Ahnenblatt 4 и «Поколения» использовались для сравнения. В переписке есть пример `OBJE / FILE`, `_PRIM Y`, `NOTE / CONC / CONT`, но нет полного исходного дерева для воспроизведения жалобы на отдельную ветку. Имена и биографии из переписки в тесты не копировались.

## Как перенести дерево с портретами

1. В исходной программе экспортировать GEDCOM в UTF-8, выбрав копирование фотографий в папку. Желательно экспортировать дерево целиком, без фильтров.
2. Поместить `.ged` и его папку фотографий в один ZIP, сохранив относительные пути. Пример:

   ```text
   tree.ged
   tree.ged.files/
       portrait.jpg
   ```

3. В Family Tree DS выбрать «Импорт» и этот ZIP. Обычный `.ged` также открывается, но Android не получает доступ к соседней папке через выбор одного документа. Если фотографии не переданы, приложение сообщает об этом до замены текущего дерева.

Поддерживаются UTF-8 (включая BOM), UTF-16 с BOM и явно объявленные Windows-1251/CP1251/ANSI. Неизвестная кодировка отклоняется с предложением экспортировать UTF-8. В ZIP должен быть один `.ged`/`.gedcom`; допускается общая вложенная папка. Учитываются обратные Windows-разделители и регистр, только если соответствие однозначно. Абсолютные пути, выход за папку и загрузка фотографий по сети не поддерживаются. Портреты: JPEG, PNG, GIF, WebP и BMP.

Импортёр читает встроенные блоки `OBJE/FILE` и ссылки `OBJE @...@` на отдельные записи, выбирает основной портрет `_PRIM Y`, восстанавливает `NOTE`, `CONT`, `CONC` и ссылки на отдельные заметки. Семейные связи собираются из `FAM/HUSB/WIFE/CHIL` и взаимных `INDI/FAMC/FAMS`; семьи с неизвестными родителями сохраняют связь между детьми. Отсутствующие записи диагностируются. Это не доказательство устранения конкретной отделившейся ветки: для этого нужен полный GEDCOM пользователя.

Ограничения: встроенные двоичные `BLOB`, нестандартные области лиц на групповых фото, видео, документы и все разновидности событий сторонних программ пока не импортируются. Нужны обезличенные образцы таких экспортов. Не следует обещать полную совместимость с любым вариантом GEDCOM.

## HTML

Один автономный файл с масштабируемой схемой, поиском, карточками людей, переходами к родственникам, датами, местом рождения, заметками и текстами воспоминаний. Портреты встраиваются как уменьшенные изображения; сеть не используется. Подходит для отправки родственникам и открытия на компьютере или телефоне. Поле поиска обеспечивает навигацию и без взаимодействия с Canvas. При большом дереве удобнее сначала найти человека.

## Импорт

В окне импорта доступны два сценария: выбрать один файл или открыть папку. Для папки отображаются только `.ftree`, `.tree`, `.json`, `.ged`, `.gedcom`, `.zip` и XML Family Tree DS. Файл можно перетащить прямо на окно приложения; проверка удерживает доступ к нему до завершения чтения. Перед заменой дерева показываются имя файла, количество персон, количество связей и предупреждения о пропущенных записях или фото.

## XML

Версия 1 схемы Family Tree DS, пространство имён `urn:family-tree-ds:export:1`: корень `family-tree`, разделы `people` и `relationships`, устойчивые идентификаторы и ссылки, раздельные части дат, заметки, тексты воспоминаний и встроенные портреты. Это выгрузка для программной обработки. Она не заявляет совместимость с XML «Древа Жизни» и обратно импортируется только в Family Tree DS; это обменный формат, а не замена полной резервной копии.

Для полного сохранения оригинальных фото, документов, альбомов и настроек остаётся `.ftree`. HTML/XML не заменяют резервную копию.

Источники: https://genery.com/wiki6/ru:file_gedcom, https://genery.com/wiki6/ru:file_xml, https://gedcom.io/specifications/ged551.pdf.
