# Готовые статьи Family Tree DS

Папка содержит готовые тексты для публикации на разных площадках. Скриншоты
лежат рядом в `screenshots/` и уже подключены в markdown:

- `00-icon.jpg` - иконка/обложка.
- `01-tree.png` - семейное дерево.
- `02-person-card.png` - карточка человека.
- `03-people-list.png` - раздел людей.
- `04-birthday-widgets.png` - виджеты дней рождения.
