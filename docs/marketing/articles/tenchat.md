# TenChat: Family Tree DS - семейное дерево и архив семьи на Android

Я запустил **Family Tree DS** - бесплатное Android-приложение для создания семейного дерева и хранения семейного архива.

![Family Tree DS: семейное дерево](screenshots/01-tree.png)

Приложение помогает собрать в одном месте:

- родственников и связи между ними;
- фотографии;
- даты рождения и ухода;
- места;
- заметки;
- семейные истории;
- документы;
- фотоальбомы;
- дни рождения.

Family Tree DS работает локально на телефоне. Для базового использования не нужна регистрация, подписка или обязательный сервер.

![Карточка человека](screenshots/02-person-card.png)

## Что уже есть

- Семейное дерево с карточками людей.
- Родительские, партнёрские, родственные и братские связи.
- Автоматическое упорядочивание дерева по поколениям.
- Каталог всех людей с поиском, фильтрами и сортировкой.
- Фотоальбомы и семейные подборки.
- Импорт и экспорт GEDCOM.
- Перенос всего дерева одним `.ftree` файлом.
- Экспорт в PDF, PNG и тайловый PNG.
- Виджеты ближайших дней рождения.
- Приватное онлайн-дерево через GitHub, если семье нужна синхронизация.

![Раздел Люди](screenshots/03-people-list.png)

## Для кого

Для семей, которые хотят сохранить родословную, фото и истории.

Для тех, кто занимается генеалогией.

Для людей, которые хотят привести семейный архив в порядок без сложных сервисов и подписок.

## Почему это важно

Семейные данные часто хранятся хаотично: в чатах, галереях, заметках, папках на компьютере. Family Tree DS помогает собрать их в понятную структуру и сохранить для родственников.
