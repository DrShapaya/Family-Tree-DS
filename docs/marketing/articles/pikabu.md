# Pikabu: Сделал приложение, чтобы не терялись семейные истории

Всем привет. Я сделал Android-приложение **Family Tree DS** для семейного дерева.

Не для того, чтобы просто нарисовать кружочки и линии, а чтобы собрать в одном месте родственников, фотографии, даты, места, заметки, документы, семейные истории и дни рождения.

![Family Tree DS: семейное дерево](screenshots/01-tree.png)

Почему вообще взялся?

Потому что семейные архивы обычно существуют в странном виде. Фото в одном чате, документы на старом ноутбуке, даты где-то в голове, а истории помнят один-два человека. И если их не записать, они просто исчезают.

Я хотел сделать приложение, которое можно открыть на телефоне и спокойно начать собирать семью.

## Что внутри

Можно добавлять людей, связывать родителей, детей, партнёров, братьев и сестёр. Есть авторасстановка дерева по поколениям, чтобы оно не превращалось в хаос.

У каждого человека есть карточка:

![Карточка человека](screenshots/02-person-card.png)

В неё можно добавить фото, даты, место, заметки, истории и файлы. То есть это не только «Иванов Иван Иванович, 1950 год», а нормальная маленькая семейная страница.

Есть список всех людей:

![Раздел Люди](screenshots/03-people-list.png)

Там поиск, фильтры, сортировка, фотографии и быстрый переход к человеку на дереве.

## Главное: без обязательного облака

Семейные данные - штука личная. Поэтому приложение работает локально на телефоне. Не нужна регистрация, подписка или аккаунт.

Если нужно передать дерево родственникам, можно сохранить всё одним `.ftree` файлом. Ещё есть импорт/экспорт GEDCOM, PDF и PNG.

Если семье всё-таки нужно общее онлайн-дерево, есть необязательный режим через приватный GitHub. Можно подключить родственников и дать им просмотр или редактирование.
