# DTF: Я сделал Android-приложение для семейного дерева, чтобы семейные истории не терялись в чатах

**Лид:** Family Tree DS - бесплатное приложение для Android, где можно собрать семейное дерево, фото, документы, истории, дни рождения и экспортировать всё в `.ftree`, GEDCOM, PDF или PNG.

![Family Tree DS: семейное дерево](screenshots/01-tree.png)

У многих семей есть один общий архив, которого на самом деле нет.

Фотографии лежат в Telegram, документы - в папке на ноутбуке, дни рождения - в голове у одного человека, а истории про прадеда или бабушку живут до тех пор, пока кто-то их помнит. В какой-то момент становится понятно: если это не собрать сейчас, потом часть семьи просто исчезнет из памяти.

Я сделал **Family Tree DS** - Android-приложение для семейного дерева и семейного архива.

Идея простая: не просто нарисовать связи между родственниками, а дать место, где можно хранить живые детали: фото, даты, места, заметки, документы, истории и дни рождения.

## Что умеет приложение

В Family Tree DS можно создавать карточки людей, связывать родителей, детей, партнёров, братьев и сестёр, автоматически упорядочивать дерево по поколениям и быстро находить нужного человека.

![Карточка человека](screenshots/02-person-card.png)

В карточке человека можно хранить:

- фотографию профиля;
- даты рождения и ухода;
- место;
- заметки;
- семейные истории;
- документы и вложения;
- дополнительные фотографии.

Отдельно есть раздел **Люди**. Это каталог всех родственников с поиском, фильтрами, сортировкой и быстрым переходом к человеку на дереве.

![Раздел Люди](screenshots/03-people-list.png)

## Почему я делал это локальным

Семейные данные - чувствительная штука. Там имена, даты, фотографии, документы, воспоминания. Поэтому базовый сценарий в Family Tree DS работает локально на телефоне.

Не нужна регистрация. Не нужна подписка. Не нужно заводить облако просто ради того, чтобы нарисовать родословную.

Дерево можно перенести одним `.ftree` файлом. Также есть импорт и экспорт GEDCOM, экспорт в PDF, обычный PNG и большой тайловый PNG для печати или просмотра на большом экране.

## Онлайн есть, но он необязательный

Если семье нужно общее дерево, можно включить онлайн-режим. Он использует приватный GitHub-репозиторий пользователя: дерево хранится там, участники подключаются по приглашению, а глава может дать человеку режим просмотра или редактирование.

Для меня было важно не поднимать отдельный сервер и не делать обязательную учётную запись внутри приложения. Онлайн - только для тех, кому он действительно нужен.

## Маленькая вещь, которая неожиданно важна
