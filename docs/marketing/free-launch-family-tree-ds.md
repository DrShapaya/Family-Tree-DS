# Бесплатный запуск Family Tree DS

## Позиционирование

Family Tree DS — бесплатное Android-приложение для семейного дерева, фотоархива,
историй, документов и дней рождений. Основной акцент: данные хранятся локально,
а при необходимости дерево можно переносить одним `.ftree` файлом, экспортировать
в GEDCOM/PDF/PNG и подключать приватную синхронизацию через GitHub.

Главная фраза:

> Семейное дерево, фотоархив и дни рождения родственников на Android — без
> подписки и без обязательного сервера.

## Страница без сервера

Самый простой вариант — статическая страница. Ей не нужен backend: только
`index.html`, картинки и ссылка на скачивание.

Подходящие варианты:

- GitHub Pages: бесплатно, удобно рядом с GitHub-релизами, можно подключить
  домен `drshapaya.ru/androidft` или `familytree.drshapaya.ru`.
- Cloudflare Pages: бесплатно для статического сайта, удобно подключать домен
  и HTTPS.
- Netlify: быстрое drag-and-drop размещение папки с сайтом.
- RuStore + GitHub Release как временная посадочная связка: в описании RuStore
  ссылка на GitHub/Telegram, в GitHub Release — APK, changelog и скриншоты.

Минимальная структура:

```text
site/
  index.html
  screenshots/
    tree.png
    person.png
    people.png
    widgets.png
```

Что должно быть на первом экране:

- название `Family Tree DS`;
- одна понятная фраза: `Семейное дерево и архив семьи на Android`;
- две кнопки: `Скачать в RuStore` и `Открыть GitHub`;
- один лучший скриншот дерева.

Блоки ниже:

- `Что умеет`: дерево, карточки, фотоальбомы, дни рождения, GEDCOM, PDF/PNG,
  `.ftree`, онлайн-дерево через GitHub;
- `Приватность`: локальное хранение, онлайн только по выбору;
- `Для кого`: семья, генеалоги-любители, хранители семейных фото;
- `Ссылки`: RuStore, Telegram-канал, Telegram-чат, GitHub, DonationAlerts.

## Готовая статья

# Я сделал бесплатное Android-приложение для семейного дерева и семейного архива

У многих семей есть одна и та же проблема: фотографии лежат в разных чатах,
даты дней рождения вспоминаются в последний момент, старые истории знают только
старшие родственники, а родословная постепенно распадается на кусочки.

Я сделал Family Tree DS — Android-приложение для семейного дерева, где можно
собрать родственников, связи, фотографии, даты, места, заметки, семейные
истории и документы в одном месте.

Приложение работает локально на телефоне. Для базового использования не нужен
аккаунт, сервер или подписка. Дерево можно сохранить одним `.ftree` файлом,
отправить родственникам, перенести на другой телефон или экспортировать в
GEDCOM, PDF и PNG.

Что уже есть:

- карточки людей с фото, датами, местами и заметками;
- родительские, партнёрские, родственные и братские связи;
- автоматическое упорядочивание дерева по поколениям;
- каталог всех людей с поиском, фильтрами и сортировкой;
- семейные фотоальбомы и отдельные подборки;
- импорт и экспорт GEDCOM;
- экспорт в PDF, обычный PNG и большой тайловый PNG;
- виджеты ближайших дней рождения;
- быстрый старт для создания первых поколений;
- приватное онлайн-дерево через GitHub, если семье нужна синхронизация.

Мне было важно сделать приложение не как облачный сервис с обязательной
регистрацией, а как личный семейный инструмент. Семейные данные чувствительные:
имена, даты, фотографии, документы и истории не должны улетать куда-то просто
потому, что человек хочет нарисовать дерево.

Онлайн-режим в Family Tree DS необязательный. Если его включить, дерево
хранится в приватном GitHub-репозитории пользователя, а родственников можно
подключать приглашениями. Можно дать человеку только просмотр или разрешить
редактирование.

Сейчас мне очень нужны честные отзывы: удобно ли создавать первое дерево,
понятны ли связи, хватает ли экспорта, нормально ли выглядят карточки и
фотоальбомы. Особенно интересно мнение тех, кто занимается родословной,
семейными архивами или просто хочет сохранить историю своей семьи.
